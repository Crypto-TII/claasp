Circle-linear trails: verification
==================================

Circle-linear trail contributions and endpoint correlations are different
quantities. A trail result reports its search scope and the keys on which it
contributes. Endpoint evaluation fixes the other inputs and evaluates the
complete primitive. V5 has no general concrete-realizability checker for a
circle-linear mask sequence.
