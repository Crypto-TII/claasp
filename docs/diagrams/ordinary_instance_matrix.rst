Bounded ordinary-instance support matrix
=======================================

This frozen matrix covers 16 specified valid catalog instances, not all primitives.
It was generated by ``check_instance_matrix.py`` with fresh workers, three ordinary
inputs per instance, explicit 512-call/20000-cell/100000-grid-cell/1MB-text limits,
and a 30-second worker budget. No audit/legacy fallback or admission change occurs.

Default persistent ASCII and TikZ each pass 3/16 instances: Speck2, ChaCha two full
rounds and Chaskey one full round. Explicit routed ASCII and TikZ each pass 6/16:
the same three, plus Simon two rounds, Simeck two rounds and Ascon one round.
Each admitted annotated export reparses to exact native IR and its reconstructed
cipher agrees with original native evaluation on all three inputs. Default and
explicit routed profiles are recorded separately, including byte hashes and timings.

Declared-observation and round-frontier state ASCII/TikZ pass 16/16 instances; their
final packed values agree with native output. Word-bank state views pass only the
same three default word instances. State support is not a claim of a persistent
circuit layout, inferred algorithmic matrix, or original placement recovery.

Exact rejection reasons and full constructor settings are in the accompanying
``matrix.json`` and ``summary.csv``. Representative limitations:

* Sbox4 with the explicit PRESENT lookup table, LinearLayer4 with an explicit
  invertible 4x4 matrix, and the 8-bit reverse PermutationCipher reject persistent
  operation projection. Native reconstruction and semantic state views still work.
* AES one round rejects mixed-width operation ports.
* PRESENT one round hits the conservative projected-call budget; this is a
  budget rejection, not proof of support or a representation-only classification.
* Alzette default and Gimli one round reject oversized inline glyph labels.
* Simon five rounds, SHA1 one round and SHA256 one round reject physical arity.
  Simon's boundary is the four-input XOR at native round index 4.

These normal instances identify priorities without modifying the representation:
explicit parameter/table-bearing S-box and linear/permutation blocks; full constant
labels/legends; agreed generic reduction grouping for n-ary nodes; and width-aware
routing/bit selections. Each requires its existing/new contract review rather than
silently changing semantic identity, output packing or lookup parameters.

Reproduce in Sage-enabled Python::

    python docs/diagrams/check_instance_matrix.py OUTPUT_DIRECTORY

Local timing samples include constructor/import/native caching effects as documented
per action; they are neither tail-performance measurements nor runtime guarantees.
The output records support separately for ASCII, TikZ and all three state modes,
exact native comparison, unsupported reasons, and conservative budget rejection.
No new rendering decision, public push, live builder or pending DES representation
is part of this checkpoint.
