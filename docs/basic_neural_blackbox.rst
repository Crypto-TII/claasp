Black-box neural distinguisher
==============================

Can a classifier distinguish plaintext/output pairs from pairs whose output is uniformly random? Compare rounds one through seven with a fresh CPU classifier at each round.

.. plot::
   :context: reset
   :nofigs:
   :include-source:

   from claasp.primitives import Speck

   primitive = Speck(number_of_rounds=7)
   result = primitive.analysis.neural_blackbox(rounds="all", samples=30000)

Print the settings, independent-test evidence and a qualified conclusion:

.. code-block:: python

   result.to_terminal()

.. plot::
   :context:
   :nofigs:
   :include-source: false

   from io import StringIO
   from pathlib import Path

   output = StringIO()
   result.to_terminal(file=output)
   Path("_build").mkdir(exist_ok=True)
   Path("_build/neural_blackbox_terminal.txt").write_text(output.getvalue(), encoding="utf-8")

   :language: text

.. plot::
   :context:
   :include-source:

   result.plot()

The curve shows **independent test accuracy** of the final model at each
round, using 1,000 fresh test examples per round. The dashed line is chance
accuracy. The shaded region is the exact two-sided binomial chance band at
95% family-wise confidence, with Bonferroni correction across the seven
planned round tests. Its width depends on the **test** sample count, rather
than the training sample count. A point outside either side of the band is
statistical evidence of a distinction; a point inside is a non-detection,
not evidence that no distinguisher exists.

Training uses 30,000 examples per round, 15 epochs, a 10% validation
split, and seed 9. The test data use a separate recorded seed and are never
used to select an epoch, difference, or training continuation. Reporting
reuses the stored measurements. ``result.plot(view="epochs")`` is available
for the validation histories used during training; these are separate from
the independent tests.

The conclusion below is generated by CLAASP from the corrected tests, rather
than assuming that falling below 0.5 means the distinguisher has stopped working:

.. plot::
   :context:
   :nofigs:
   :include-source: false

   Path("_build/neural_blackbox_conclusion.txt").write_text(result.conclusion + "\n", encoding="utf-8")

Below-chance accuracy can also reveal a distinguisher if the deviation is
repeatable: reversing binary predictions changes accuracy ``a`` to ``1 - a``.
CLAASP checks both directions and labels significant negative deviations as
``below chance``. A proposed inversion should be confirmed on fresh data.
See :doc:`neural_distinguishers` for the statistical interpretation.

Download :download:`the script <examples/basic_neural_blackbox.py>`.
Continue to :doc:`advanced_neural_blackbox` for experiment parameters and interpretation.

The 30,000-sample budget lets this small model learn the one-round structure.
The smaller default training budget did not reliably expose that structure.
