================================================================================
DATA EXTRACTION
================================================================================

From each log file, the script extracts:
  ✓ Seed number (from filename: test_lea_*_seed_X.log)
  ✓ Upper weight (from: "Upper weight = X.X")
  ✓ Lower weight (from: "Lower weight = X.X")
  ✓ Middle weight (from: "Middle weight = X.X")
  ✓ Trail weight (from: "Trail weight = X.X")
  ✓ Execution time (from: "Done (overall time X.XX s)")

Derived Calculations:
  p = 2^(-upper_weight)
  q = 2^(-lower_weight)
  r = 2^(-middle_weight)
  total_probability = p² × q² × r
